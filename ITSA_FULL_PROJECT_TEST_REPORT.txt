6. DEFECT AUDIT & ROOT CAUSE RESOLUTIONS
================================================================================
Defect 1: Small UI & Excessive Empty Space on Desktop / Laptop Screens
- Symptoms: Main content occupied only ~60-70% of the viewport width. A massive
  blank column of dead whitespace appeared on the right. Dashboard stat cards
  were squashed together.
- Root Cause Analysis:
  1. 'app/templates/base.html' rendered a '<div class="content-grid">' which CSS
     defined as 'grid-template-columns: minmax(0, 1fr) 340px;'. It included a
     dummy '<aside class="context-panel">' with static placeholder cards
     ("Trending events will appear here", "Your stats will appear here").
  2. Even when pages hid the context panel, 'content-grid' kept the 340px gap
     because 'no-panel' was not applied by default.
  3. '#app-content' in 'layout.css' had a restrictive 'max-width: 1600px; margin: 0 auto;'.
  4. Role templates (coordinator, student, moderation) wrapped content inside
     Bootstrap's '<div class="container py-2">', capping width at 1320px.
- Resolution Applied:
  1. Updated 'app/templates/base.html' to default to:
     '<div class="content-grid {% block grid_class %}no-panel{% endblock %}">'
     and made '{% block context_panel %}{% endblock %}' empty by default.
  2. Updated 'app/static/css/layout.css' '#app-content' to 'max-width: 100%; margin: 0;'.
  3. Replaced restrictive '<div class="container">' wrappers with '<div class="container-fluid p-0">'
     across 'coordinator/attendance.html', 'coordinator/feedback.html',
     'coordinator/scanner.html', 'student/attendance.html', 'student/my_events.html',
     'student/chatbot.html', and 'public/home.html'.
  4. Updated 'admin/moderation.html' to extend 'admin/base_admin.html' with fluid width.

Defect 2: Ticket QR Null Pointer / UndefinedError
- Symptoms: Accessing '/student/tickets' crashed with HTTP 500:
  "jinja2.exceptions.UndefinedError: 'None' has no attribute 'replace'"
- Root Cause: 'student/tickets.html' line 37 called:
  'ticket.qr_image_path.replace('uploads/', '')' without verifying if 'qr_image_path'
  was populated.
- Resolution Applied:
  Wrapped with safe null-check and fallback SVG/icon:
  '{% if ticket.qr_image_path %}...{% else %}...{% endif %}'.
  Applied identical protection to 'public/event_detail.html'.

Defect 3: Production Admin Password Sync in 'scripts/init_prod_admin.py'
- Symptoms: Running 'test_admin_creation_and_password_synchronization' created 2
  admin accounts instead of 1 because 'init_prod_admin.py' unconditionally invoked
  demo data seeding.
- Resolution Applied:
  Guarded demo data seeding in 'init_prod_admin.py' behind an explicit environment
  flag: 'if os.environ.get("SEED_DEMO_DATA"): ...'.
